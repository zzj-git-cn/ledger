记账本 · 使用说明
============================

【怎么打开】
双击本文件夹里的「记账本.html」即可(任意浏览器都能打开,推荐 Chrome / Edge)。
用同一个浏览器打开,数据才是同一份。

【数据存在哪】
存在浏览器本地(IndexedDB,失败自动退回 localStorage),不联网、不上传。
关掉浏览器再打开,记录还在。

【扇形图(收支构成)】
统计表一打开就能看到:扇形图和「近 N 天走势」并排放在首屏,不用往下滚。
右上角能切「今日 / 本周 / 本月 / 总览」。
- 外环:深红 = 支出、深绿 = 收入,环的长度就是各自占比
- 内环:各分类占自己那一半(餐饮、快递、交通…用深浅不同的红色,收入用深浅不同的绿色)
- 鼠标悬浮某个分类 → 弹出这段时间里它的各个下一级金额(点里面的小行 = 只看这一级明细)
- 分类没有下一级(比如工资、理财)时,悬浮直接显示总额
- 悬浮框右上角的「→」箭头,或直接点扇区 = 下方明细只筛这一级、时间跟随上面选的周期
- 下面「分类排行」里点任意一行,同样只筛这一类的本月明细(每行下面还带二级小字)

【补录以前几天的账】
首页右上角「日历+」图标 → 补录。
- 一次能填很多笔,每笔单独选日期(时间默认"现在",事后也能改)
- 日期可以先在上方选一个,点「统一日期」套用到所有行
- 只会追加新记录,现有数据一笔都不会被改动
- 保存后右下角会弹一个「撤销本次补录」,点一下就能撤回
- 打开补录时、以及点保存前,都会自动存一份快照

【万一弄错了怎么救】
右上角「数据库」图标 → 「从自动备份恢复」,能把数据还原成补录之前的样子。
恢复后如果后悔,提示条上有「撤销恢复」,可以再换回来。
(自动备份是单独存的,不会覆盖你的正常记录)

【备份(建议每月一次)】
打开记账本 → 右上角的「数据库」图标 → 导出 JSON 备份。
换电脑或重装系统前,先导出一次。

【常用操作】
- 记一笔:右下角 + 支出 / + 收入,也可以按 Alt+E / Alt+I
- 金额框能算数:输入 20-8 会自动算出 12
- 收入里的「工资 / 兼职」可以按小时算:填小时数 × 时薪
- 分类选「其他」时必须写用途(例如红包),写过的用途会记住最近 5 个,点一下就能填
- 首页「本月支出预算」点一下就能设置,会显示进度条和剩余额度
- 快捷键:Alt+1 统计表,Alt+2 支出,Alt+3 收入

【预算预测刻度】
预算进度条上那根**白色竖线**就是「按目前速度,月底会花到哪」;下面一行会写清楚:
「按目前速度,月底预计 X 元(超预算 Y / 在预算内,还能再花 Y)」。超预算时竖线变红。

【卡片上的环比小箭头】
当日/本周/本月三张卡下面会跟一行,例如 `↑ 18.20 较昨天`——
和时间**上一期同一时段**比净额(今天到现在 vs 昨天同一时段;本周至今 vs 上周同期;本月至今 vs 上月同期)。
绿色 = 比上期好,红色 = 比上期差;上一期完全没记录时会直接写「昨天没有记录」,不会给假数字。

【想改分类】
用记事本打开「记账本.html」,顶部有一段 CATS 配置,
一级分类和里面的 subs 小类照着格式加就行(名称、图标、颜色都能改)。

【文件夹里的东西】
- 记账本.html   软件本体,双击使用,所有记录和配置都在这
- 记账本.ico    图标文件,想给文件夹换图标可以右键文件夹 → 属性 → 自定义 → 更改图标
