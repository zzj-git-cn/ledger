# 记账本 · 单文件本地记账

一个**单文件 HTML** 的个人记账工具:双击就用、不联网、数据只存在你自己浏览器里。

> 无依赖(纯原生 HTML/CSS/JS + 手写 SVG)、无构建步骤、无后端、不上传任何数据。

![界面截图](screenshot-app.png)

## 功能

**打开就能看到的统计表**
- 四张概览卡:当日 / 本周 / 本月 / 全部结余(收入大于支出显示 `+`)
- 每张卡带**环比小箭头**:`↑ 18.20 较昨天`——和时间上一期**同一时段**比净额(今天到现在 vs 昨天同一时段、本周至今 vs 上周同期、本月至今 vs 上月同期)
- **本月支出预算**:进度条 + 百分比 + 剩余额度 + 日均可用;进度条上有一根**预测刻度**,告诉你"按目前速度月底会花到多少、会不会超"
- **收支构成扇形图**:两级同心环——外环深红支出 / 深绿收入按占比分,内环各分类用**同一色系的深浅**区分;悬浮看下一级明细,点击筛明细
- **近 N 天走势**:收入/支出柱 + 当日净额折线,底部附带峰值日、日均支出、最大一笔
- **分类排行**(两级,带二级小字)+ **本月日历**(按当天消费深浅上色,点格子按天筛)
- **检索**:日期预设(今天/本周/本月/上月)+ 自定义起止 + 收支类型 + 分类(支持一到三级)+ 关键词

**记一笔(尽量少打字)**
- 金额框支持算式:`20-8` 自动算成 12
- 收入里的「勤工助学 / 校内兼职」可切 **按小时算**:填工时 × 时薪自动出金额
- 分类选「其他」时必须写用途(如红包),写过的用途会记住**最近 5 个**,点一下即可
- 保存后自动沿用上次选的分类,连续记账不用重复点

**补录旧账**
- 一次填多笔,每笔单独选日期,可一键「统一日期」
- **只追加、不改动任何已有记录**;保存后可一键「撤销本次补录」

**数据管理**
- 导出 CSV(带 BOM,Excel 不乱码)、导出/导入 JSON 备份(按 id 去重合并)
- 打开补录、点保存前自动写快照;可「从自动备份恢复」,恢复后还能「撤销恢复」

**快捷键**:`Alt+1/2/3` 切板块,`Alt+E/I` 直接记支出/收入,`Ctrl+Enter` 保存

## 怎么用

**方式一:本地打开**
1. 下载 `index.html`(或 `记账本.html`,内容一样)
2. 双击,用 Chrome / Edge 打开
3. 数据会自动存在这个浏览器里

**方式二:GitHub Pages(推荐,手机也能用)**
1. 仓库 → Settings → Pages → Source 选 `main` 分支根目录 → Save
2. 等一分钟,访问 `https://<你的用户名>.github.io/<仓库名>/`
3. 手机浏览器打开同一个网址即可——是正常的 https 来源,存储稳定
   (但仍然:**手机和电脑各自一份数据**,不会自动同步,见下)

## 数据 & 隐私

- 所有记录只存在**你自己浏览器的 IndexedDB**(失败自动退回 localStorage),页面不联网、不上传
- **换设备 / 换浏览器 = 换一份数据**;要搬数据就「导出 JSON → 在另一台导入」
- 建议每月导出一次 JSON 备份
- 数据在浏览器缓存里,清理站点数据会一起清掉,所以**备份很重要**
- MIT 协议,代码可随意使用/修改/分发,但**你的账目数据不在仓库里**

## 技术说明

- 单文件,`CATS` 常量在文件顶部:一级分类、二级/三级小类、颜色、图标、`hourly`(按时薪算)、`cust`(需手写文字)都可直接改
- 图表全部是手写 SVG(同心环、折线柱状图),无图表库
- 存储:`IndexedDB`(主)+ `localStorage`(备),另有独立的自动快照 key
